# Security policy

Zorlo's agent can read and write files, run commands and fetch web pages on the machine it runs on, so
security reports matter.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository.

Include what an attacker can do, the steps to reproduce it, and the Zorlo version. You'll get a reply
within a few days, and a fix will be released before the issue is made public.

## Supported versions

Only the latest release gets security fixes.
